# Release checklist

- [ ] CI is green on `main`
- [ ] package version and release notes are synchronized
- [ ] CLI help and README match shipped behavior
- [ ] module inventory is current
- [ ] report-schema changes are documented
- [ ] new detector behavior has deterministic tests
- [ ] evidence/redaction tests pass
- [ ] dependency changes have been reviewed
- [ ] security and contribution guidance is current
- [ ] a clean-install smoke test succeeds
