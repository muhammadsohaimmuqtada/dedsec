# Roadmap

1. Prove the shared runtime foundation across supported Python versions.
2. Migrate high-noise HTTP detectors to the centralized transport and candidate/verified semantics.
3. Add request-level evidence.
4. Add normalized asset and endpoint stores.
5. Add dependency-aware discovery and scheduling.
6. Remove legacy executors and request paths.
7. Prepare the breaking-change boundary for a true 2.0.0 package release.
